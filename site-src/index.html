01 / What it does

One review.
Six kinds of leverage.

OpenRabbit is not a single comment generator. It is a complete review surface: the walkthrough, the line-level findings, the security lane, the conversation, and the machine-readable output.

A review a human can actually read.

Every PR gets an executive summary, a changed-file table, effort estimate, risk assessment, release notes, and an optional sequence diagram. The comment is updated on new commits — never duplicated.

02 / Review pipeline

From webhook to walkthrough, without the wait.

Webhook endpoints answer quickly, reviews run in the background, and duplicate deliveries are dropped before they can create duplicate comments.

01

Point a provider at it

one URL · signed

Create a webhook for pull requests, review comments, and issue comments. OpenRabbit validates the provider signature before reading the event.

POST /api/webhooks/github
202 accepted · queued
02

Queue, dedupe, retry

bounded concurrency

The job queue keeps repeated deliveries from redelivering the same review. Transient failures retry with backoff. Activity shows every attempt.

completed delivery ignored
retry 2/3 · backoff
03

Read the whole context

diff + repository

OpenRabbit checks out the PR into a temporary workspace, runs the review engine and optional scanners, then removes the checkout. Repository code is never executed.

03 / Architecture

Your code takes the shortest path home.

There is no OpenRabbit cloud in the middle. The review service runs beside your data, behind your firewall, under your upgrades.

01
No hosted middlemanProvider events reach your tunnel or reverse proxy, not a shared SaaS control plane.
02
Bring your own model — or noneThe built-in static engine needs no key. Use OpenAI, Anthropic, Gemini, or Ollama when you want more.
03
Authentication is not optionalProduction requires an admin token. Sessions are signed, expiring, HttpOnly cookies. Webhooks require signatures.
04
A checkout with an exitRemote reviews use a temporary clone with hooks disabled, host allowlisting, and guaranteed cleanup.
